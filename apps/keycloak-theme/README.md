# Keycloak theme

The pages Keycloak renders for the platform (sign-in, account setup, invitations, two-factor),
drawn as in `.design/auth.pen` with the console's design tokens. Built with
[Keycloakify](https://www.keycloakify.dev); ADR-0033 explains why.

- `pnpm --filter keycloak-theme dev` serves every page with a mock context:
  `http://localhost:5174/?page=login-password.ftl`, any Keycloak template name.
- `src/login/KcPage.tsx` has one case per page the design draws, in `src/login/pages`; any
  other page is Keycloakify's default inside `src/login/template.tsx`.
- `src/kc.gen.tsx` is generated by `pnpm exec keycloakify update-kc-gen`; never edit it.
- The jar is built by `deploy/compose/keycloak.Dockerfile`, which needs no local Java. With Maven
  installed, `pnpm --filter keycloak-theme build-keycloak-theme` writes it to `dist_keycloak/`.
